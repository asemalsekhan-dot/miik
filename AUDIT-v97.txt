مِعِك — تقرير الفحص التقني للنسخة 97
===================================

الفحوص المنفذة:
- فحص JavaScript لكل كتل <script> بواسطة node --check.
- فحص تكرار معرفات DOM (id).
- فحص تكرار معرفات style وscript.
- فحص الدوال العالمية القديمة المتكررة على مستوى الملف.
- فحص الاعتمادات الحرجة لمحرك التقارير print86/css86.
- فحص وجود الأصول المطلوبة للنسخة (شعار الوزارة، شعار مِعِك، واتساب، PDF القواعد، رسم غلاف المدرسة).

النتيجة:
- عدد كتل JavaScript: 62.
- أخطاء Syntax: 0.
- معرفات DOM المكررة: 0.
- معرفات script المكررة: 0.
- معرفات style المكررة: 0.
- print86 و css86 متاحتان عالميًا عبر window.

التراكمات القديمة المكتشفة:
- توجد 21 تسمية لدوال top-level مكررة بإجمالي 29 تعريفًا زائدًا في الطبقات القديمة، أبرزها openCalendar و addReminder و renderPlan و recordProgram و openOwner.
- توجد كذلك عدة window.* overrides تاريخية لأن المشروع بُني تراكميًا عبر إصدارات كثيرة. هذه ليست أخطاء Syntax، وبعضها مقصود لتغليب أحدث سلوك.
- لم تُحذف هذه التعريفات بالجملة في v97 لأن تجربة التنظيف الجماعي السابقة أثبتت أن بعض التعريفات المبكرة مطلوبة أثناء بدء التشغيل قبل وصول المتصفح إلى التعريفات الأحدث. تنظيفها يحتاج refactor مرحلي مع اختبار runtime بعد كل مجموعة، وليس حذفًا آليًا.

إصلاحات v97 المتعلقة بالسلامة الوظيفية:
- الجلسة الجماعية تحفظ كسجل واحد مع قائمة المشاركين، وتظهر كذلك عند فتح ملف أي طالب مشارك.
- واجهة التواصل مع ولي الأمر لم تعد تعتمد على اختيار طالب مسبقًا من ملف الطالب.
- التقرير الشامل يستخدم محرك الطباعة العام الموجود بدل إنشاء طبقة طباعة مستقلة إضافية.
- الغلاف وصفحة البسملة منفصلان، ولا يوجد شعار مِعِك على الغلاف أو صفحة البسملة؛ الهوية تظهر عبر الألوان والتكوين.

ملاحظة هندسية:
- أفضل خطوة تنظيف مستقبلية: تجميع الدوال العالمية القديمة في وحدات محددة وإزالة override chains تدريجيًا مع smoke test فعلي في المتصفح بعد كل مرحلة.
